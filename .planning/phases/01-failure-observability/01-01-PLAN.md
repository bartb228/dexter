  RED first. Write tests/test_summarize_rejections.py, then implement to pass.

  Signature: `summarize_rejections(rejections: List[Tuple[str, List[str]]], *, screened: int,
  passed: int, max_samples: int = 8) -> Dict`. `rejections` is [(symbol, failures), ...] for
  NON-passing, NON-errored symbols only.

  Returns a dict:
    {"screened": int, "passed": int, "rejected": len(rejections),
     "gate_tally": {canonical_gate: count_of_symbols_blocked_by_it, ...} sorted desc by count,
     "samples": [{"symbol": s, "failures": [...]} for first max_samples rejections]}

  Bucketing rule: map each failure STRING to a canonical gate key by matching its leading
  token BEFORE coding — grep scoring.py for the exact `failures.append(...)` prefixes and
  build a prefix→key map. Canonical keys: "ROIC", "Debt/Eq", "CurrentRatio", "ROE",
  "IntCoverage", "PEG", "RevGrowth", "MarketCap", "P/E", "P/B", plus "Other" fallback for
  anything unmatched (so no reason is silently dropped). A symbol counts ONCE per distinct
  gate it violates (dedupe the keys per symbol before tallying). EXCLUDE operational
  non-gate reasons: any failure starting "rate_starved:" or containing "sector_excluded="
  (these are infra skips, not quality-gate fails) — such symbols are NOT in `rejections`
  (Task 3 filters them), but guard defensively so they bucket to a dropped "operational"
  set that is NOT counted in gate_tally.

  Determinism: gate_tally must be an insertion-ordered dict sorted by (-count, key) so the
  same inputs always serialize identically (mirror the determinism discipline in
  classify_tier tests). No Date/random.

  Test cases (enumerate ALL, count = 9):
  1. Empty rejections → {screened, passed, rejected:0, gate_tally:{}, samples:[]}.
  2. Single symbol, single failure "ROIC=0.10 < 15% (quality_moat floor)" → gate_tally {"ROIC":1}.
  3. Single symbol, MULTIPLE failures (KO-like: ROIC + Debt/Eq + CurrentRatio + RevGrowth)
     → each gate counted once; samples[0].failures has all 4.
  4. Two symbols both failing ROIC → gate_tally {"ROIC":2}.
  5. fail-closed strings ("ROIC=unavailable ...", "IntCoverage=unavailable ...") bucket to
     "ROIC"/"IntCoverage" (NOT "Other") — regression guard for D4.
  6. Duplicate gate within one symbol's failures list → counted once (dedupe).
  7. Unrecognized failure string → buckets to "Other", still appears, not dropped.
  8. gate_tally ordering: 3×CurrentRatio, 5×ROIC, 1×PEG → keys ordered ROIC, CurrentRatio, PEG.
  9. samples capped at max_samples (pass 12 rejections, max_samples=8 → len(samples)==8,
     but rejected==12).

  Run: cd "/Users/Ambartsum/code/Stock scanner/scanner" && python3 -m pytest tests/test_summarize_rejections.py -q
  </action>
